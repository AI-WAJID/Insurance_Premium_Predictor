Predict your health insurance premium in seconds.

This web app estimates your annual health insurance premium using a machine learning model trained on real-world data. Enter a few basic details—age, BMI, smoking status, region and dependents—and get an instant, transparent prediction.

The model is built with RandomForest Regressor using Scikit-Learn on top of a Django backend, with data processing handled by Pandas and visual experimentation done via Matplotlib.

Why use this predictor?

  • Data-driven estimate: The model learns patterns between features such as age, BMI and smoking status to estimate your premium instead of using fixed, hard-coded rules.
  • Transparent inputs: You control every input. Change a single factor like region or smoker status and immediately see how it impacts the predicted premium.
  • Educational: Ideal for understanding how different lifestyle and demographic variables can influence health insurance costs.
  • Open for customization: The project is designed so developers can extend it, retrain the model on new data, or integrate it into larger systems.

How it works

1. Collect inputs

You provide basic information such as age, gender, BMI, number of children, smoking status and residential region.

2. Process with ML model

These inputs are fed into a RandomForest Regressor trained on a popular health insurance dataset to learn complex non-linear relationships.

3. Display your estimate

The model outputs a predicted annual premium, which is formatted and displayed instantly on the prediction page for you to review.

Tech stack

The project uses Django for backend and routing, Tailwind CSS for styling, and a Scikit-Learn RandomForest Regressor model trained and evaluated using Pandas and Matplotlib. This combination makes it a solid end-to-end example of deploying a machine learning model inside a production-ready web application.
